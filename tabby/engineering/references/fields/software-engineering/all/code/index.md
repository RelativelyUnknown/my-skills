# Code

Read `snags.md` before you finish any function. Read the rest only when the task touches it.

- snags.md: habits that look fine and are wrong: signatures, errors, time, structure. Always.
- snags-control-flow.md: `finally`, `zip`, mutating while looping, retries, `open` without `with`.
- errors.md: raising, catching, chaining, a batch where some items fail.
- validation.md: parsing input at an edge into typed values.
- minimalism.md: adding a function, class, option, constant or wrapper; naming.
- stdlib-first.md: hand-rolling a utility or adding a package.
- typing.md, typing-patterns.md: annotations, checker errors, TypedDict, Protocol, generics.
- resources.md, resource-patterns.md: files, connections, locks, subprocesses, temp files, streams.
- python-versions.md: a feature that may be newer than the Python target.
- comments.md: writing a docstring or comment.
- logging.md, security-basics.md: logging, secrets, SQL, subprocess, `eval`, `pickle`.
- complexity.md: `xenon` or `radon` reports a rank.
- scripts.md: a one-file script or small CLI.
