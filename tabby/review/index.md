# Python review

Defaults: read the `## Python defaults` section of AGENTS.md; use the `report` value for the format.

Read `review/changes/self-review.md` and follow it.

A change that crosses between Python and Rust, C or C++: also read `review/native-boundary.md`.

For a security audit, read `review/security-audit/process.md` and `review/security-audit/reporting.md` instead. If the user asks to audit or review the whole repository (not a diff), read `review/repo-audit.md`. If the audit covers dependencies, CI workflows or the release path, also read `review/security-audit/supply-chain.md`.
