# Software architecture

- design-patterns.md: a pattern is requested, a refactor adds classes or layers, an extension point is needed.
- fit.md: choosing a data structure, representation, algorithm or API shape; what to know about the workload and the project's plans first.
- senior-engineering.md: questions to ask about assertions, resource limits, confining `unsafe`, owning your own pace, and workarounds that should expire. Read before a design decision, not after.
- senior-engineering-examples.md: the real code behind each question (TigerBeetle, polars, Spark, DeepSeek).
- fit-examples.md: worked examples from ruff, uv, polars and pandas.
