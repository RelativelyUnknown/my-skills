# Code

Read `smells.md` before you finish any function. Read the rest only when the task touches it.

- smells.md: habits that look fine and are wrong: errors, time, files, signatures, structure, comments. Always.
- errors.md: raising, catching, chaining, a batch where some items fail.
- validation.md: parsing input at an edge into typed values.
- minimalism.md: adding a function, class, option, constant or wrapper; naming.
- reuse.md: before hand-rolling a utility or adding a package: the ladder (project, standard library, community standard, niche or your own).
- typing.md: annotations, checker errors, TypedDict, Protocol, generics.
- resources.md: files, connections, locks, subprocesses, temp files, streams.
- python-versions.md: a feature that may be newer than the Python target.
- comments.md: writing a docstring or comment.
- logging.md, security-basics.md: logging, secrets, SQL, subprocess, `eval`, `pickle`.
- scripts.md: a one-file script or small CLI.
