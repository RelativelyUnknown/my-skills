# Testing

Read `testing.md` for any test work. It names the rigor level and what else to read.

- testing.md: never-miss rules, writing tests, rigor levels.
- mocking.md: mocking boundaries, time, randomness, retries, async.
- fixtures.md: fixtures and `conftest.py`.
- property-based.md: Hypothesis (rigor `ultra`).
- mutation.md: mutation testing (rigor `ultra`).
- gates.md: lowest-supported dependencies, installed-wheel test, coverage gate.
- redesign.md: only when the task explicitly asks for a redesign.
- smells.md: tests that cannot fail, edited tests, sleeps, state not restored. Read when writing or changing a test.
