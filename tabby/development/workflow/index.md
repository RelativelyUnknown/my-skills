# Workflow

- planning.md: before a non-trivial change; when to stop and ask; what never to do unasked.
- debugging.md: a bug, a failing test, a race.
- shipping.md: before you say done; report format by `report` level.
- refactoring.md: restructuring code without changing behaviour; pin it first.
- checking-apis.md: calling a third-party API you are not sure of; check the installed version, not memory.
