# Written documentation

Pick by what the reader is doing.

- tutorial.md: learn by doing, as a beginner.
- how-to.md: reach a goal they already have.
- reference.md: look something up (API, CLI, config).
- explanation.md: understand why or how it works.
- docstrings.md: docstrings and API reference.
- readme.md: a README.
- changelog.md: changelog, release notes, deprecation notices.
- governance/: CONTRIBUTING.
- placing.md: a page fits no type or mixes two.
- voice.md: voice, structure and content rules for any page.
- style.md: word choice, punctuation, numbers, dates, UI text, procedures.
- concision.md: tightening prose.
- ai-patterns.md: reviewing a draft for AI writing patterns.
- code-examples.md: code samples and shell commands.
