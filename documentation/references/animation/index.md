# Animation

A minimalist explainer animation: SVG scenes drawn as a pure function of time, rendered with headless Chromium and encoded with ffmpeg.

- pipeline.md: setting up the engine, writing a scene, previewing, building.
- motion.md: the motion vocabulary, timing, the loop, and copy-ready recipes.
- formats.md: encoding frames to MP4, WebM and GIF.
- ../diagrams/style.md: the visual language (read before writing any scene).
