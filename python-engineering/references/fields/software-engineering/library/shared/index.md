# Library, all kinds

Templates are in the skill's `assets/`: `pyproject.toml`, `Makefile`, `ci.yml`, `release.yml`.

- api-design.md: adding, renaming or removing a public name, signature, exception or extra.
- package-setup.md: a new package, or editing build, lint, type-check or CI config.
- layout.md: package structure, modules, where a file goes.
- tooling.md: type checker, build backend, hooks, free-threaded CI.
- entry-points.md: console scripts.
- versioning.md: where the version lives.
- release.md: build, verify, publish, fix a broken wheel.
