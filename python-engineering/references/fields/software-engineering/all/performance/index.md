# Performance

Measure before you change anything.

- profiling.md: find where time or memory goes (start here).
- hot-path-fixes.md: the profile names a hot spot; fixes in order of leverage.
- faster-libraries.md: a measured hot path is too slow; which library for the job.
- replacement-packages.md: the job is not listed, or the library does not fit; how to find and judge one.
- benchmarking.md: prove a change with numbers.
