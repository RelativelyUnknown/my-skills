# All Python projects

Read `code/snags.md` and `workflow/shipping.md` for every code change, then the folder that matches the task:

- code/: writing or changing source: errors, types, resources, naming, comments, security.
- testing/: adding, fixing or reviewing tests.
- performance/: slow or memory-heavy code, benchmarks, a faster library.
- dependencies/: adding, auditing or locking dependencies; uv.
- workflow/: planning a change, debugging, finishing and reporting.

Read that folder's `index.md` first.
