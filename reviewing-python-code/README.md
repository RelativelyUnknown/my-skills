# reviewing-python-code

Part of the [skills repository](../README.md). Reviews a Python diff, branch or pull request, or your own change before you report it done: bugs, silenced or weakened checks, unneeded abstractions, public API breaks, new dependencies. A clean diff gets a short "no findings".

`SKILL.md` points to `references/changes/self-review.md`. It reads the rule leaves in `python-engineering/references/`, so install both skills. Security audit, compliance and per-project-type checklists are planned.

`evals/clean-diff-no-noise` checks that a clean diff gets no invented findings.
